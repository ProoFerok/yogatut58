# Йога тут — сайт студии

Статический сайт без сборки: `index.html` + `style.css` + `script.js` + папка `assets/`.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```
npx serve .
# или
python3 -m http.server 8080
```

## Структура

- `index.html` — вся разметка, секции: герой, Елена, услуги, «три шага», отзывы, заметки, контакты.
- `style.css` — токены цветов и шрифтов в `:root`, адаптив через media queries (телефон / планшет / десктоп).
- `script.js` — логика видео в герое: буферизация, старт через 3 с после готовности, пауза вне экрана и при уходе с вкладки.
- `assets/` — фото студии, видео `hero.mp4` (720×1280, без звука, 4,2 МБ) и постер.
